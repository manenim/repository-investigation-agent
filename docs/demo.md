# Five-minute demonstration

1. Open the local service. Explain that the public Vercel page is a saved-report viewer; live generation is authenticated in FastAPI.
2. Select `manenim/gateway-rate-limiter` and `main`. Choose GitHub issue URL and enter `https://github.com/manenim/gateway-rate-limiter/issues/1`, or paste: **Redis errors still return Pong** / **Trace pingHandler errors versus denied decisions and propose a compatible fix and validation plan.**
3. Enter the local demo access token and submit. Watch ingestion resolve a full commit SHA, retrieval select evidence, and the three model stages progress independently of the HTTP request.
4. Read the architecture and observation sections. Open a citation; verify that its GitHub link contains the exact commit and original line range. Expand the stored excerpt.
5. Inspect each claim's reference validity, support judgment and quotation. Show any unsupported/insufficient-evidence result. Explain that the semantic verifier is fallible and a quote is not proof of entailment.
6. Read hypotheses and counter-evidence. Show that fixes and correctness/performance checks are proposals, while tests actually run against the target repository are explicitly none.
7. Export Markdown and JSON. JSON includes the immutable source snapshot, model/prompt versions, usage, timings and verification results.
8. Restart the app and retrieve the same completed report. Show that an interrupted run is marked failed and must be resubmitted.
9. Ask a question about an unspecified production outage. Expect insufficient evidence, not an invented root cause.

For portfolio viewing without access credentials, open the public sample report. It is a saved actual model result, with no hidden live generation behind the button.
